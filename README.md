# Служба технической поддержки университета

Веб-сервис автоматизации процесса обработки заявок в службу технической поддержки университета.

Сайт разработан на стеке: Python 3, Flask, SQLAlchemy, SQLite, Jinja2, python-docx, openpyxl.


## Возможности

- Три роли с разграничением доступа: **Заявитель**, **Специалист поддержки**, **Администратор**.
- Публичная часть: 11 основных страниц.
- Личный кабинет заявителя: список заявок, создание заявки с вложением, карточка заявки,комментарии, профиль, уведомления.
- Кабинет специалиста: очередь заявок с фильтром, обработка, ведение базы знаний, статистика.
- Админ-панель: управление пользователями и ролями, справочники, учёт оборудования,
  реестр всех заявок, управление базой знаний, отчеты.
- Генерация документов: акт выполненных работ (.docx) и сводный отчёт по заявкам (.xlsx).
- Адаптивная вёрстка, хлебные крошки, обработка ошибок 401/403/404/500.

## Установка и локальный запуск

```
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python seed.py        # создаёт helpdesk.db и наполняет тестовыми данными
python run.py         # http://127.0.0.1:5000
```

## Структура проекта

```
helpdesk/
├── app/
│   ├── __init__.py        # фабрика приложения, регистрация blueprints, обработчики ошибок
│   ├── extensions.py      # экземпляры db и login_manager
│   ├── models.py          # 13 моделей данных
│   ├── decorators.py      # разграничение доступа по ролям
│   ├── auth.py            # регистрация, вход, выход
│   ├── main.py            # публичные страницы
│   ├── tickets.py         # кабинет заявителя
│   ├── specialist.py      # кабинет специалиста
│   ├── admin.py           # админ-панель
│   ├── documents.py       # генерация .docx и .xlsx
│   ├── templates/         # HTML-шаблоны (public, auth, cabinet, specialist, admin, errors)
│   ├── static/css/        # адаптивный стиль
│   └── uploads/           # вложения к заявкам
├── config.py
├── run.py                 # точка входа
├── seed.py                # наполнение БД
├── helpdesk.db            # файл БД
└── requirements.txt
```

## Модель данных (13 таблиц)

Role, User, Department, Category, Priority, Status, Ticket, Comment,
Attachment, Equipment, KnowledgeArticle, TicketHistory, Feedback.
